PromptOptimizer v1.0
====================

PromptOptimizer 是一个仅支持 Windows 的绿色提示词优化工具。程序没有主窗口，运行后驻留在系统托盘。

首次使用
--------
1. 将 PromptOptimizer.exe 放到一个普通用户可写的目录。
2. 双击运行，程序会在同目录生成 config.json。
3. 右键托盘图标，选择“设置”。
4. 填写 api_key，按需修改 base_url、model 等字段并保存。
5. 右键托盘图标，选择“重新加载配置”。

日常使用
--------
1. 在任意软件中选中要优化的文本。
2. 按住 Ctrl，快速连续按三次 A（每次间隔不超过约 0.5 秒）。
3. 完成提示出现后，按 Ctrl+V 粘贴优化结果。

程序通过 Windows UI Automation 直接读取当前焦点控件中的选区，不会模拟 Ctrl+C，也不会通过剪贴板获取输入。如果没有选中文字，或当前应用不支持 UI Automation 文本选区，程序会给出简短提示。
运行状态会以不抢焦点的圆角小提示显示在当前输入框或文本光标附近；无法定位输入控件时显示在鼠标附近。

常用配置
--------
- base_url：OpenAI 兼容服务的 API 根地址，默认 https://api.openai.com/v1。
- model：服务支持的模型名称。
- hotkey：全局热键。默认 Ctrl+TripleA，表示“按住 Ctrl，快速三击 A”；也支持 Ctrl+DoubleA 和普通组合键（如 Ctrl+F8）。
- system_prompt：发送给模型的系统提示词。
- play_sound：成功后是否播放系统提示音。
- result_mode：当前固定为 clipboard，仅复制结果到剪贴板。
- auto_start：是否为当前 Windows 用户启用登录后自动运行。

注意事项
--------
- config.json 中的 API Key 以明文保存在本机，请不要分享该文件。
- 只有待优化文本、系统提示词和请求参数会发送到配置的 API 服务。
- 输入侧不会读取或修改剪贴板；输出侧只写入 Unicode 文本结果。
- 部分游戏、远程桌面、自绘控件和未公开 UI Automation 文本选区的应用无法直接读取选中文本。
- 程序不会记录历史提示词或常规运行日志。
- 修改配置后必须点击“重新加载配置”才会生效。
- Ctrl+TripleA 会拦截完整三击手势；未完成手势时，原本的 Ctrl+A 会在短暂等待后正常传给当前程序。
- 修改 hotkey 后，请通过托盘菜单重新加载配置。

退出
----
右键托盘图标，选择“退出”。
