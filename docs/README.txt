PromptOptimizer v0.3.0
====================

PromptOptimizer 是一个仅支持 Windows 的绿色提示词优化工具。程序没有主窗口，运行后驻留在系统托盘。

系统要求
--------
- Windows 10 或 Windows 11。
- 设置窗口依赖 Microsoft Edge WebView2 Runtime；多数 Windows 10/11 系统已预装。

首次使用
--------
1. 将 PromptOptimizer.exe 放到普通用户可写目录。
2. 双击运行，程序会在 EXE 同目录生成 config.json。
3. 右键托盘图标，选择“设置”。
4. 在“模型与服务”“优化规则”“应用行为”中修改配置。
5. 可先点击“测试连接”，再点击“保存并应用”。

模型配置
--------
- 每套 API 配置可以保存多个模型。
- 在“可用模型”中每行填写一个模型名称。
- 使用“当前模型”下拉框选择这套配置实际调用的模型。
- 切换 API 配置时，各配置的模型列表和当前选择分别保存。
- 旧版只有 model 字段的 config.json 会自动迁移，原模型仍作为当前选择。

日常使用
--------
1. 在支持 Windows UI Automation 文本选区的应用中选中待优化文本。
2. 按住 Ctrl，快速连续按三次 A（每次间隔不超过约 0.52 秒）。
3. 等待状态提示变为“已复制”。
4. 按 Ctrl+V 粘贴优化结果。

v0.3.0 更新
-----------
- 设置窗口升级为 WebView2 渲染的 Apple / Win11 风格界面，支持系统深浅配色。
- 每套 API 配置支持多个模型，并可选择当前调用模型。
- 新增自绘配置下拉框、胶囊 Toggle、键盘焦点态、高对比度和窄窗口布局。
- 切换配置前自动暂存当前表单，测试连接不会覆盖未保存输入。
- 温度和最大 Token 数使用严格校验，并正确支持 temperature = 0。
- WebView2 初始化失败时显示明确错误；关闭设置窗口后尽力清理本次临时数据目录。
- Toast 浮窗支持 DPI 缩放。

注意事项
--------
- config.json 中的 API Key 以明文保存在本机，请勿提交或分享该文件。
- 程序只向配置的 API 服务发送当前选区、系统提示词和请求参数。
- 输入侧不读取或覆盖剪贴板；输出侧只写入最终 Unicode 文本。
- 部分游戏、远程桌面及自绘控件可能无法提供 UI Automation 文本选区。
- 设置窗口中的修改需点击“保存并应用”才会写入 config.json 并生效。

退出
----
右键托盘图标，选择“退出”。
